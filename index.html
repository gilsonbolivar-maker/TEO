      Sugestões prontas

      Lembrete diário

      O programa não envia notificação sozinho. Para ser cutucado todo dia no mesmo horário, crie uma automação no app Atalhos (iPhone/iPad):

      1. Abra Atalhos → aba Automação → +
      2. Escolha Hora do Dia e defina o horário (ex.: 21h)
      3. Repetir: Diariamente · Executar: Imediatamente
      4. Ação: Abrir app → selecione Teo

      No Android, use um lembrete diário no Google Agenda apontando para o site.
